# Finars Studio 1.1

Modern, Apple-inspired website for **FIN ARS d.o.o.** — architectural studio from Zagorje ob Savi, Slovenia.

## Features
- Clean, sophisticated design (desktop + mobile)
- Project gallery with lightbox zoom
- Animated hero background
- Pages: Home, Projects, About, Services, Contact
- Individual project detail pages with original images from finars.si

## Live preview
After enabling GitHub Pages (Settings → Pages → Deploy from branch `main` / root), the site will be available at:

**https://tommyvimeo-gif.github.io/Finars-Studio-1.1/**

## Local use
Open `index.html` in a browser, or serve with any static server.

## Images
Place original project images into the `images/` folder (downloaded from the original finars.si project pages).  
The full image set is available in the accompanying zip from the previous conversation.
